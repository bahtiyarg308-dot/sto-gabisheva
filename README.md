# С. Т. О. на Габишева

Одностраничный сайт автосервиса (Казань, ул. Комиссара Габишева, 8А).
Без сборки: `index.html`, `prices.json`, папки `images` и `fonts`.

- Цены, часы работы и фото меняются в `prices.json`. Инструкция: «Как менять цены и фото.txt».
- Номер счётчика Яндекс Метрики: строка `METRIKA_ID` в `index.html`.
- Локальный просмотр: `python3 -m http.server` в этой папке (двойной клик по файлу не покажет цены).
